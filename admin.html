📖 如何获取 CORS 代理地址？

浏览器直接调用第三方 API 会被跨域策略拦截，需要部署一个代理。推荐使用 Cloudflare Workers（免费）：

  1. 打开 dash.cloudflare.com → Workers & Pages → 创建 Worker
  2. 将项目中的 cors-proxy-worker.js 内容粘贴进去 → 部署
  3. 复制 Worker URL（如 https://mushroom-proxy.xxx.workers.dev）
  4. 粘贴到上方"代理地址"输入框

每天 10 万次免费请求，完全够用。

⚠️ API Key 保存在浏览器 localStorage 中，仅管理后台可配置。
